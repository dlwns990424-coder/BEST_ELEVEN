# BEST ELEVEN

원하는 축구 선수를 직접 선택하고 배치하여
나만의 팀을 만들 수 있는 모바일 중심 스쿼드 메이커입니다.

FC Online 선수 데이터를 활용해 선수를 검색하고,
포메이션과 포지션 제한 없이 자유롭게 팀을 구성할 수 있도록 제작했습니다.

### 배포 사이트

https://dlwns990424-coder.github.io/BEST_ELEVEN/

## 프로젝트 소개

축구 팬이라면 누구나 자신이 좋아하는 선수들로  
직접 최고의 팀을 구성해보고 싶다는 생각에서 시작했습니다.

기존 게임 기반 스쿼드 메이커처럼 급여, 포지션, 팀 컬러 등의 규칙에 제한받지 않고  
원하는 선수를 자유롭게 선택하고 배치할 수 있도록 제작했습니다.

## 핵심 기능

- **선수 검색 및 후보 선수 등록**  
  FC Online 선수 데이터를 활용해 이름으로 선수를 검색하고 원하는 선수를 후보 목록에 등록할 수 있습니다.
  - 선수 이름 검색
  - 최대 23명 등록
  - 동일 선수 중복 추가 방지
  - 선수 이미지 Fallback 처리

  <img width="373" height="820" alt="선수검색" src="https://github.com/user-attachments/assets/570b3da5-67a5-4b2c-9672-26d010351952" />

- **Drag & Drop 선수 배치**  
  후보 선수와 경기장 사이에서 Drag & Drop을 활용해 원하는 위치에 자유롭게 선수를 배치할 수 있습니다.
  - 후보 선수 → 경기장 배치
  - 경기장 선수 간 위치 교환
  - 경기장 선수 → 후보 목록 복귀
  - 포지션 제한 없는 자유 배치
  - 랜덤 선수 배치

  <img width="365" height="810" alt="선수 드래그 배치" src="https://github.com/user-attachments/assets/322a5744-84a3-4369-b02a-3f97965509a7" />

- **포메이션 선택 및 변경**  
  총 8개의 포메이션을 제공하며, 포메이션을 변경해도 기존에 배치한 선수들이 최대한 유지되도록 구현했습니다.

<img width="368" height="793" alt="포메이션" src="https://github.com/user-attachments/assets/517f9904-5abc-469e-b511-d12d22eba68b" />

- **팀 저장 및 관리**  
  로그인한 사용자는 자신이 만든 팀을 저장하고 다시 불러와 수정하거나 삭제할 수 있습니다.
  - 사용자별 팀 저장
  - 저장된 팀 불러오기
  - 기존 팀 수정
  - 선택 삭제
  - 최신순 · 오래된순 · 이름순 정렬
  - 생성일 · 최근 수정일 표시
