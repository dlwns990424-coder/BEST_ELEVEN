# BEST ELEVEN

원하는 축구 선수를 직접 선택하고 배치하여
나만의 팀을 만들 수 있는 모바일 중심 스쿼드 메이커입니다.

FC Online 선수 데이터를 활용해 선수를 검색하고,
포메이션과 포지션 제한 없이 자유롭게 팀을 구성할 수 있도록 제작했습니다.

### 배포 사이트

https://dlwns990424-coder.github.io/BEST_ELEVEN/

## 프로젝트 소개

축구 팬이라면 누구나 자신이 좋아하는 선수들로  
직접 최고의 팀을 구성해보고 싶다는 생각에서 시작했습니다.

기존 게임 기반 스쿼드 메이커처럼 급여, 포지션, 팀 컬러 등의 규칙에 제한받지 않고  
원하는 선수를 자유롭게 선택하고 배치할 수 있도록 제작했습니다.

## 핵심 기능

- **선수 검색 및 후보 선수 등록**  
  FC Online 선수 데이터를 활용해 이름으로 선수를 검색하고 원하는 선수를 후보 목록에 등록할 수 있습니다.
  - 선수 이름 검색
  - 최대 23명 등록
  - 동일 선수 중복 추가 방지
  - 선수 이미지 Fallback 처리

## 프로젝트 회고

이번 프로젝트에서는 이전 프로젝트에서 경험했던 문제들을 바탕으로  
개발 전 데이터 검증과 기능 범위 설정, 모바일 환경 테스트를 조금 더 적극적으로 진행했습니다.

### 아쉬운 점 및 배운 점

### API 사전 검증의 중요성

초기에는 선수 이름과 이미지뿐만 아니라 포지션 등의 데이터를 활용해 다양한 기능을 구현하려고 했습니다.

하지만 실제 FC Online 데이터를 직접 호출하고 확인하는 과정에서  
처음 예상했던 방식으로 활용하기 어렵다는것을 확인했습니다.

그 결과 불필요한 기능을 제거하고 선수 이름과 이미지를 중심으로 프로젝트 범위를 다시 정리했습니다.

이를 통해 외부 API나 데이터를 사용하는 프로젝트에서는 개발을 시작하기 전에  
실제 응답 데이터와 활용 가능한 범위를 먼저 확인하고 실제로 구현이 가능한지 체크해보는 과정이 정말 중요하다는것을 다시금 느꼈습니다.

### Drag & Drop 상태 관리

Drag & Drop 기능을 구현하면서 단순히 선수 카드의 위치만 변경하는 것이 아니라  
후보 선수 목록과 경기장 배치 상태를 함께 관리해야 했습니다.

경기장에 배치된 선수는 후보 목록에서 제외하고,  
다시 후보 영역으로 이동하면 목록에 표시되도록 여러 상태가 서로 일관되게 유지되어야 했습니다.

이를 통해 여러 컴포넌트가 하나의 데이터를 공유하는 기능에서는  
UI 구현단계에서 계획이 변경되지 않게 상태 구조와 데이터 흐름을 먼저 정리하는 점이 정말 중요하다는것을 많이 느꼈습니다.

### UX 관련 문제점

실제 모바일에서 테스트하는 과정에서 배치된 선수 카드를 터치한 상태로 스크롤하려고 하면 페이지가 스크롤되지 않고 Drag 동작이 먼저 인식되는 문제가 있었습니다.

이 때문에 선수 카드가 없는 영역을 터치해야만 자연스럽게 스크롤할 수 있다는 불편함이 있었습니다.

이러한 문제 등 정말 사소한 부분까지 UX를 고려하여 기획, 개발을 진행해야한다는 점을 많이 느꼈습니다.
